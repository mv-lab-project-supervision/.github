# Student Projects

This GitHub organization hosts repositories for bachelor's and master's thesis or similar projects.

The purpose is to support transparent, reproducible, and well-documented research and development.

## Collaboration Principles

- **Version control:** All projects use Git to maintain a traceable development history.
- **Continuous progress:** Students are expected to commit regularly and report progress at least once a week.
- **Documentation:** Repositories should document objectives, methodology, experiments, results, and important decisions.
- **Reproducibility:** Source code, configurations, and instructions should allow results to be reproduced whenever possible.
- **Transparency:** Development history should provide evidence of the work performed throughout the project.

## Repositories

Each student receives a dedicated private repository. Repository access is restricted to the student and their supervisors.

Completed projects may be made public when appropriate and agreed upon.
